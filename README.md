# fp-growth-color-blindness

This was the final project completed for CSCI2810: Advanced Computational Molecular Biology at Brown University. The presentation slides for the project can be found [here] (https://docs.google.com/presentation/d/1qth_5EYFfQh1ZGYRNsgqH1xHauxLVCWZq7ZMldFkpxM/edit?slide=id.p#slide=id.p).

The project was done by taking people's self-uploaded SNP data from OpenSNP and running an implementation of the FP-Growth algorithm on it and then analyzing the baskets created.
